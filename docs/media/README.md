# README imagery

- `banner.svg` is a self-contained illustration of the stepped clipboard mark. The warm paper and clay colours belong to the README artwork; the app itself uses the dark interface shown below it.
- `history.png` and `always-available.png` are unmodified copies of the native production-view renders in `video/native-capture/renders/`, created with `video/native-capture/VideoRender.swift`. The fixture contains synthetic demo values and does not read the clipboard, Keychain, or hosted services.

Keep these files in the repository so the README works without remote image services. Screenshots should always show the current CleverClipboard name and use synthetic data.
